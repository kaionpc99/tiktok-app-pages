Política de Privacidade

Última atualização:

Este aplicativo é uma ferramenta pessoal que utiliza a API oficial do TikTok (Content Posting API) para enviar vídeos como rascunho à caixa de entrada de uma conta do TikTok autorizada pelo próprio usuário.

Quais dados são acessados

O aplicativo acessa apenas o token de acesso (access token) e token de renovação (refresh token) gerados pelo fluxo OAuth 2.0 do TikTok, necessários para autenticar os envios de vídeo. Esses tokens são armazenados localmente, apenas no computador onde o aplicativo é executado.

O que NÃO é coletado

O aplicativo não coleta, armazena ou compartilha dados pessoais do usuário, senha da conta do TikTok, nem conteúdo de terceiros além dos vídeos que o próprio usuário escolhe enviar.

Compartilhamento de dados

Nenhum dado é compartilhado com terceiros. Os tokens e vídeos processados permanecem apenas entre o dispositivo do usuário e os servidores oficiais do TikTok.

Revogação de acesso

O usuário pode revogar o acesso do aplicativo à sua conta TikTok a qualquer momento, diretamente nas configurações de aplicativos conectados do TikTok.
